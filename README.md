# Twój grafik · Android beta

Instalowalna aplikacja Android dla grafiku zmianowego 12 h.

## Beta zawiera
- działanie offline,
- cykl zmian D / N / wolne,
- brygady A–D,
- dniówkę 06:00–18:00 i nockę 18:00–06:00,
- nawigację po miesiącach,
- jasny i ciemny motyw,
- szczegóły dnia i lokalne notatki,
- podsumowanie liczby zmian i godzin.

Wrzesień 2026 dla brygady A jest zakotwiczony zgodnie z potwierdzonym grafikiem: 7 dniówek, 8 nocek, 15 zmian, 180 h.

APK jest budowane automatycznie przez GitHub Actions.
